🧑‍🏫 Teacher Mode

What are students learning?
The difference between an AI's built-in knowledge and information a person supplies, how instructions shape tone and behaviour, and why AI should admit uncertainty instead of guessing.
What are the three stages?
Build (name, avatar, personality), Train (add and edit knowledge cards) and Test (chat, check answers, then go back to Train to improve). The loop Train → Test → re-train is the point of the activity.
What AI model is this?
This activity uses SmolLM2-360M-Instruct, a small open language model (about 360 million parameters) chosen specifically because it's light and fast enough to run smoothly in a browser on ordinary school laptops. The MODEL_ID constant near the top of the script can be swapped for a larger model (e.g. a Qwen model) if you want stronger general knowledge and have faster classroom devices — replies will be slower.
What does Transformers.js do?
It's a JavaScript library that runs AI models inside the browser using ONNX Runtime Web, with WebGPU acceleration where available and a CPU/WASM fallback otherwise.
Why does it run in the browser?
No server, account or database is needed. Nothing a student types leaves their device — it's ideal for a classroom with safeguarding requirements.
What does "teaching" the bot actually mean?
Students are not retraining the model. Their knowledge cards and instructions are added as context alongside each question, which the model reads before answering. Only the cards relevant to the question are included each time.
How do knowledge packs work?
A pack is just a quick way to add a set of ready-made cards. They are ordinary cards: students can edit them, and the bot's answers change immediately. There are no pre-written answers — everything the bot says is generated from the current card text.
What does the "remembers the chat" slider do?
It controls how many of the previous question-and-answer pairs are shown to the model with each new question — a simple way to see how an AI's short-term memory works.
Why does the bot sometimes say "I don't know"?
It's designed to only rely on its own general knowledge or what the student typed — and to say so honestly when neither covers the question. Questions about the student ("my favourite…") with no matching card always get an honest "I don't know".
Where is a student's work saved?
Their working bot lives in sessionStorage and clears when the tab closes. "Save current bot" stores it in localStorage on that device, and Export / Share link let them move it elsewhere. Nothing is sent to a server.
How is it accessed?
The activity is a static site hosted on GitHub Pages, shared with students via a short Bitly link — no install required.
