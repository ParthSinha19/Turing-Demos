🧑‍🏫 Teacher Mode

What are students learning?
How a simple chatbot finds answers from information a person supplies, how instructions shape tone and behaviour, and why a bot should admit when it doesn't know instead of guessing.
What are the three stages?
Build (name, avatar, personality), Train (add and edit knowledge cards) and Test (chat, check answers, then go back to Train to improve). The loop Train → Test → re-train is the point of the activity.
What kind of chatbot is this?
A rule-based, keyword-matching chatbot. There is no AI model to download, so it loads instantly, works offline after the first visit and runs on any school laptop. Nothing a student types leaves their device.
How does it find an answer?
1) It splits the question into key words, ignoring little words like "the" and "is". 2) It scores every card: a match in the topic is worth 3 points, a match in the body text 1 point. 3) The best-scoring card wins; a student's card beats a built-in note on the same topic. 4) The answer is built from the card's own sentences and dressed in the bot's personality. The "How did I answer?" button under each reply shows the matched words.
How is this different from ChatGPT-style AI?
This bot can only repeat what is on its cards. A large language model generates new sentences from patterns in huge amounts of text. It's a good discussion point: which is more predictable, and which is more flexible?
How do knowledge packs work?
A pack is just a quick way to add a set of ready-made cards. They are ordinary cards: students can edit them, and the bot's answers change immediately. There are no pre-written answers — every reply is built from the current card text.
What does the "remembers the chat" slider do?
With memory on, the bot can follow up ("Tell me more", "Is it big?") by remembering the last topic. With memory off it forgets, which shows how an assistant's short-term memory works.
Why does the bot sometimes say "I don't know"?
When no card or built-in note matches, it says so honestly. Questions about the student ("my favourite…") with no matching card of their own always get an honest "I don't know".
Where is a student's work saved?
Their working bot lives in sessionStorage and clears when the tab closes. "Save current bot" stores it in localStorage on that device, and Export / Share link let them move it elsewhere. Nothing is sent to a server.
How is it accessed?
The activity is a static site hosted on GitHub Pages, shared with students via a short Bitly link — no install required.
