🧑‍🏫 Teacher Mode

What are students learning?
The difference between an AI's built-in knowledge and information a person supplies, how instructions shape tone and behaviour, and why AI should admit uncertainty instead of guessing.
What AI model is this?
This activity uses SmolLM2-360M-Instruct, a small open language model (about 360 million parameters) chosen specifically because it's light and fast enough to run smoothly in a browser on ordinary school laptops. The MODEL_ID constant near the top of the script can be swapped for a larger model (e.g. a Qwen model) if you want stronger general knowledge and have faster classroom devices — replies will be slower.
What does Transformers.js do?
It's a JavaScript library that runs AI models inside the browser using ONNX Runtime Web, with WebGPU acceleration where available and a CPU/WASM fallback otherwise.
Why does it run in the browser?
No server, account or database is needed. Nothing a student types leaves their device — it's ideal for a classroom with safeguarding requirements.
What does "teaching" the bot actually mean?
Students are not retraining the model. Their knowledge cards and instructions are added as context alongside each question, which the model reads before answering.
Why does the bot sometimes say "I don't know"?
It's prompted to only rely on its own general knowledge or what the student typed — and to say so honestly when neither covers the question.
Why no accounts or database?
Everything is stored in the browser's sessionStorage only, for privacy and simplicity, and clears when the browser tab/session ends.
How is it accessed?
The activity is a static site hosted on GitHub Pages, shared with students via a short Bitly link — no install required.
