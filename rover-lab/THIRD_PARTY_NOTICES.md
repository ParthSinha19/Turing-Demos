# Third-party notices and asset attribution

Rover Lab is built on third-party open-source packages declared in `package.json`. Their licence files and copyright notices are distributed with their respective package releases and should be retained when installing or redistributing those packages. The main runtime libraries include React, Three.js, React Three Fiber, Drei, Zustand, TanStack Start/Router, Tailwind CSS, Lucide React and the TypeScript/Vite/Vitest toolchain. Consult each package's included `LICENSE`/`NOTICE` file for its exact licence terms.

No external rover model, Mars terrain mesh, texture image, soundtrack or stock image is bundled. The rover and scene geometry are generated by the project source; terrain and rock textures are generated at runtime in `src/environment/proceduralTextures.ts`. User-created level data is stored in browser local storage.

The app optionally loads IBM Plex Sans, IBM Plex Sans Condensed and IBM Plex Mono from Google Fonts. Those fonts are served by Google Fonts at runtime rather than copied into this package; local system-font fallbacks are defined in the stylesheet.

The original source archive did not contain a project-level `LICENSE` file. This package therefore does not add or imply an open-source licence for Rover Lab's own source code. Choose and add an appropriate project licence before publishing or accepting external contributions.
